## ChatGPT用プロンプト例

**マップ**
> 真上から見下ろした2Dゲーム用の戦場マップ背景。乾いた草原と土の地面、
> 所々に小さな石と草。陣取りゲームの盤面として邪魔にならない、
> 低コントラストで均一なテクスチャ。UI・文字・キャラクターは入れない。横長3:2。

**戦士(色違い4種。同じ絵柄で色だけ変える)**
> 2Dゲーム用の戦士キャラクター。真上やや斜め見下ろし視点、
> 兜と鎧、剣と盾を持つ。デフォルメしたかわいいフラットなイラスト、
> 太めの輪郭線。マントと鎧のメインカラーは【青/赤/緑/金】。
> 背景は透明(PNG)。正方形、キャラは中央、余白少なめ。

ポイント: 4体を別々に頼むと絵柄がズレるので、1体目を作った後
「この戦士とまったく同じ絵柄・ポーズで、色だけ赤にして」と続けて依頼する。
