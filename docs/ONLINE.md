# オンライン対戦

## 遊び方
1. タイトル画面の「オンライン対戦」で名前を入れて **部屋を作る**
2. 表示された **部屋コード**(英数字5文字)か **招待リンク** を友達に送る
3. 友達は部屋コードを入れて **参加**(招待リンクなら自動で入力される)
4. ホストが **対戦開始**。空き枠は CPU で埋められる(チェックで切替、難易度はホストが選ぶ)

- 最大4人。倒れたら観戦モード(生き残っている一番強い戦士を追う)
- 終了: 時間切れ / 人間が全員倒れた / 生き残りが1人
- 試合中に切断した人の戦士は CPU が引き継ぐ。ホストが抜けると試合は終了

## しくみ
- **P2P(WebRTC)**: 部屋を作った人(ホスト)のブラウザで試合を計算し、参加者は操作(向き・ダッシュ)を送って盤面を受け取る
- 接続の仲介に PeerJS の公開サーバー(0.peerjs.com)を使う。専用サーバーの用意は不要で、GitHub Pages のまま遊べる
- 盤面は変化したマスだけを差分で送信(1人あたり約6KB/秒)。約10秒ごとに全体を送り直す
- ライブラリ: `vendor/peerjs.min.js`(PeerJS 1.5.5, MIT, `vendor/PEERJS_LICENSE`)
- コード: `src/net.js`(通信・同期)、`src/main.js`(ロビー・入力)

## 注意
- ホストのタブを裏に回すとブラウザが処理を止めるため、試合が止まる(ホストは画面を前面に)
- 会社や学校など厳しいネットワークでは P2P がつながらないことがある
- PeerJS の公開サーバーは無料の共有サービスのため、混雑・停止時はつながらない。安定させたい場合は自前の PeerServer を立てて `src/net.js` の `new window.Peer(...)` に host を指定する

## テスト
- `node tests/sim.js` に同期テスト(差分送信で盤面が一致するか)
- 同じブラウザの2つのタブで `index.html?net=local` を開くと、PeerJS を使わずに(BroadcastChannel で)ロビー〜対戦を試せる
